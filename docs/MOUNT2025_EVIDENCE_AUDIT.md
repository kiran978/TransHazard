# Mount et al. (2025) supplemental evidence expansion — source audit

Original user-provided source: `vgae070_supplementary_data.pdf`, 37-page supplement to DOI 10.1093/etojnl/vgae070. Table S3 contains replicate survival, biomass, and log-logistic curve-fit output. The original PDF is **not redistributed** in the public repo.

## Distinct evidence units

- **16 original fitted endpoint rows** from 8 assay sets (the original supplement contains 9 tests including a DDD pilot lacking a fitted endpoint).
- **12 provisional comparisons**, representing **five chemical transformations**, because two endpoints and repeated o,p'-DDT tests must stay distinguishable.
- **No new independent source publications**. All 12 observations share a single study and a connected DDT chemical family.
- **Zero approved model labels**. Published numerical estimates and confidence limits do not substitute for independent adjudication.

## Scientific cautions

1. p,p'-DDE curve-fit nonuniqueness requires dose-response sensitivity review before endpoint release.
2. p,p'-DDMU biomass methanol blank vs negative control differs significantly (paper supplement p.33, reported p=0.004); retain as separate biomass HOLD.
3. o,p'-DDT test 1 vs test 2 has 7-day LC50 1.40 vs 0.60 ug/L; never treat repeated parent tests as two independent routes.
4. DDD test 1 does **not** report a fitted LC50; do not fabricate a label.
5. The 10-day o,p'-DDT test is a different duration and cannot pair with 7-day o,p'-DDD.
6. Component-wise confidence-limit ratio envelopes are **not** formal 95% CIs of paired toxicity-change effects. They do not account for covariance or all model-fitting uncertainty.
7. Each chemical was tested in a separate experiment; additional assay comparability, concentration analytical basis, route environmental evidence, and scientific reviewer approval are required.
8. Derived S4.1 toxic-unit approximations are not original experimental endpoints and were excluded.

The 2026-10-13 GitHub six-priority file is unchanged. Three of these Mount comparisons overlap with it; DO NOT combine row counts without deduplication by source assay IDs and endpoint.

Regenerated files are evidence for reviewer triage, *not* a model training set.
